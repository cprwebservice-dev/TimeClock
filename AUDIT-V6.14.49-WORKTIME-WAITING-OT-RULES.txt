AUDIT — TimeAttendance V6.14.49
Work Time / Waiting / OT Rules Consistency
============================================================

FINDINGS BEFORE FIX
[ISSUE 1] Generic Calculation Core used one first_in -> last_out span across the day.
          For split work, planned WAITING was subtracted, but actual OUT1 -> IN2
          was not the canonical source of waiting/work duration.
[ISSUE 2] Generic OT rule was paid_work_minutes - daily OT threshold for every
          Work Template. This did not match the requested per-mode OT rules.
[ISSUE 3] Scheduling Rule extension was written AFTER the main Schedule save
          recalculation. Waiting/OT could remain calculated with the old mode

[ISSUE 4] Popup Split Wait preview showed gross working windows but did not show
          standard break/net work/OT rule clearly.
[ISSUE 5] Person Schedule split label did not distinguish Normal+Late Customer
          from Split Wait Night consistently.

V6.14.49 CANONICAL RULES
1. WAITING
   - Prefer actual Shift1 OUT -> Shift2 IN when both exist.
   - Fallback to planned Shift1 end -> planned Shift2 start.
   - WAITING is never paid work and never OT.

2. NET WORK FOR TWO-SHIFT MODES
   - Shift1 work = actual IN1 -> OUT1, not earlier than planned Shift1 start.
   - Shift2 work = actual IN2 -> OUT2, not earlier than planned Shift2 start.
   - Gross work = Shift1 + Shift2.
   - Break deducted once using existing daily break rule (>= 5h => configured break).
   - Net/Paid work = Gross - Break.

3. OT
   NORMAL
   - OT = actual OUT after planned Shift end.

   NORMAL_LATE_CUSTOMER
   - OT = actual worked duration of Shift2, starting no earlier than planned Shift2 start.
   - Shift1 remains regular working period.

   SPLIT_WAIT_NIGHT
   - OT = max(0, Net work - standard_work_minutes).
   - Regular = min(Net work, standard_work_minutes).

   HOUR_BASED
   - OT = actual OUT after the computed Shift end.
