CONFIRMED BUGS FOUND AND FIXED

[CRITICAL-1] V6.14.47 Attendance rebuild reintroduced legacy PC-based expected_day
- V6.14.47 called get_expected_day_by_schedule(...pc...).
- That conflicts with V6.14.25 where configured Work Pattern weekly_off_dows is authoritative.
- V6.14.48 adds _ta_expected_workday_v61448:
  Full-day Leave -> Daily Plan override -> explicit Shift -> Public Holiday -> Work Pattern weekly_off_dows.
- No PC/position expected-day call remains in rebuild_attendance_workday.

[CRITICAL-2] Calendar dates used UTC toISOString in multiple modules
- In Thailand (+07), local midnight -> toISOString() can become the previous calendar date.
- Affected paths included PERSON hidden neighbor dates, Time Certification overnight end,
  Today buttons/defaults, Copy Previous Week, Work Pattern month dates, Shift Requests,
  notifications, reports and Night Sequence isoAddDays.
- V6.14.48 adds TimeClockCalendarV61448 and uses timezone-safe calendar arithmetic.

[HIGH-3] Quick Action all-blocked Night Sequence could throw ReferenceError
- Schedule Pro called sequenceBlockMessageV61435 outside its module scope.
- V6.14.48 exports sequenceBlockMessage from TimeClockSchedulingRulesV6120 and uses it safely.

[HIGH-4] Attendance Detail > Time Certification could throw ReferenceError
- certifyAttendance() called attendanceDetailRow() from another IIFE/module scope.
- V6.14.48 uses the local attendanceRow(emp,date) source.

[HIGH-5] Work Pattern save wrote standard_work_minutes = scheduled minutes
- Example risk: 6D scheduled 540 + break 60 was saved as standard 540 instead of net 480.
- V6.14.48 frontend computes standard = scheduled - break.
- Backend repairs only the exact old corruption signature and installs a 5D/6D minutes guard.

[HIGH-6] Paired/generated OFF could be treated as working when Shift Master cache was stale/missing
- Some legacy UI checks only excluded OFF/HOL/LV.
- V6.14.48 centralizes OSTD/OS043/OS134/OS135/OH5*/OH6* as non-working,
  while explicit real working shifts continue to override natural weekly/public holidays.
