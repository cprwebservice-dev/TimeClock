Time-Clock Enterprise V6.11.46 — Personal Monthly Schedule

ปรับเฉพาะหน้า ปฏิทินจัดกะ > มุมมองรายบุคคล

1. มุมมองรายบุคคลเปลี่ยนจาก 1 สัปดาห์ เป็นเต็มเดือน
   - โหลดวันที่ 1 ถึงวันสุดท้ายของเดือน
   - ปุ่มก่อนหน้า/ถัดไปเปลี่ยนเป็น เดือนก่อน / เดือนถัดไป
   - ปุ่มช่วงปัจจุบันเปลี่ยนเป็น เดือนปัจจุบัน

2. Label ในแต่ละวันแสดงเฉพาะ "รหัสกะ"
   - เช่น D5, D6, N5, N6, OFF, HOL, LV
   - ลดความกว้างช่องให้เหมาะกับการดูทั้งเดือน

3. วางเมาส์บน Label แสดง Tooltip
   - รหัสกะ
   - เวลาเริ่มต้นกะ – เวลาสิ้นสุดกะ
   - ถ้ามี 2 กะ แสดงเวลากะที่ 2 เพิ่มใน Tooltip และมีสัญลักษณ์ 2 บน Label

4. การลากเลือกหลายช่อง / Copy / Paste / Quick Shift / Undo / Redo / Double Click แก้กะ
   คงเดิม

5. มุมมองทีม
   - ยังคงแสดงรายสัปดาห์
   - Navigation รายสัปดาห์คงเดิม
   - ตารางและสรุปรายทีมคงเดิม
   - ระบบจำช่วงสัปดาห์ของทีมแยกจากเดือนของรายบุคคล

ไม่ต้องรัน SQL
