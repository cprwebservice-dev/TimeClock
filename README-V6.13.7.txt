Time-Clock Enterprise V6.13.7 — Compact Full-Month Person Schedule

ฐาน: V6.13.6 Icon-only Person Schedule

ปรับเฉพาะ UI ตารางกะรายบุคคล • เต็มเดือน
- ช่องวันที่ 1–28/29/30/31 พยายามแสดงครบในจอเดียวบน Desktop
- ลดความกว้างคอลัมน์รหัส/ชื่อ/วันเริ่มงาน/ตำแหน่งเฉพาะ Full-Month
- หัววันที่แสดงเลขวันที่ + ชื่อวันย่อ ไม่แสดงชื่อเดือนซ้ำทุกช่อง
- Icon กะยังคงขนาดอ่านง่าย และรายละเอียดกะอยู่ใน Tooltip เหมือน V6.13.6
- คำนวณความกว้างอัตโนมัติตามพื้นที่จริงของหน้าจอ
- จอแคบจริงยังคง Horizontal Scroll เป็น fallback เพื่อไม่บีบ Icon เล็กเกินไป
- Backend / SQL / Shift Code / Scheduling Rules / Quota / Calculation ไม่เปลี่ยน

1. ไม่ต้องรัน SQL เพิ่ม หาก V6.13.5 ติดตั้งครบแล้ว
