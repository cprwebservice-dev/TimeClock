Time-Clock Enterprise V6.11.49
Monthly Personal Layout + Person Full-Month Employee Scope

1) MONTHLY PERSONAL OVERVIEW
- จัด Day Card ใหม่ให้สมดุลขึ้น
- ลำดับข้อมูล: วันที่/สถานะ > กะ > เวลาเข้าออก > ความผิดปกติ > รับรอง/จัดกะ
- ย้าย Badge รับรองเวลาไป Footer ด้านล่าง
- ปุ่มรับรองเวลาเป็น Icon ขนาดเล็กตาม V6.11.48
- ปุ่มจัดกะย่อเป็นปุ่ม "✎ กะ"
- Footer ของแต่ละวันจัดแนว Badge และ Action ให้อยู่ระดับเดียวกัน
- ลดพื้นที่ว่างและแก้ปัญหาองค์ประกอบเบียดกัน
- Light/Dark Mode รองรับเหมือนเดิม

2) ตารางกะรายบุคคล • เต็มเดือน
- มุมมองรายบุคคลจะโหลดพนักงาน "ทั้งหมดที่ผู้ใช้มีสิทธิ์เห็น"
  ภายใน User Scope + พื้นที่ + หน่วยงานที่เลือก สำหรับเดือนนั้น
- ช่องค้นหาพนักงานเป็น Client-side Search บนชุดข้อมูลทั้งหมดที่โหลดแล้ว
- การพิมพ์รหัสพนักงานจะไม่ทำให้ Backend โหลดเฉพาะคนนั้นใน Person View อีก
- แก้เคสค้นหาคน A แล้วเปลี่ยนไปค้นหาคน B แต่ไม่พบจนต้องกด "โหลดตารางกะ"
- เมื่อเข้า Person View ด้วยข้อมูลเก่าที่โหลดแบบจำกัด ระบบจะ Auto Reload Full Month
- เปลี่ยนพื้นที่/หน่วยงานใน Person View จะ Auto Reload ข้อมูลให้ทันที
- Team View คงพฤติกรรมเดิม

หมายเหตุ:
"พนักงานทั้งหมด" หมายถึงพนักงานทั้งหมดภายใต้สิทธิ์ User Scope และตัวกรองที่เลือก
ไม่ใช่พนักงานนอก Scope ของผู้ใช้งาน

3) เดือนที่แสดง
- เพิ่ม Banner เดือน/ปีขนาดใหญ่ในมุมมองรายบุคคล
- เช่น "สิงหาคม 2569"
- แสดงช่วงวันที่และจำนวนวัน
- แสดงจำนวนพนักงานที่โหลดตาม User Scope

ไม่ต้องรัน SQL
