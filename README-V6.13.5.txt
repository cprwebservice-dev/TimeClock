V6.13.5 - Cross-Month Day-off Resolver

หลักการวันหยุดใหม่
- รหัส OFF ยังคงปิดใช้งาน
- วันหยุดใช้ Paired Day-off Shift จาก Set Up เช่น STD->OSTD, S043->OS043
- เมื่อกำหนด “วันหยุดตามกะล่าสุด” ระบบย้อนหา Effective WORK shift ล่าสุดสูงสุด 60 วัน
- การค้นหาข้ามเดือนได้ และข้ามกะวันหยุด / วันลา / นักขัตฤกษ์
- หากไม่พบกะทำงานย้อนหลัง ระบบใช้ Default Shift ของ Work Pattern แล้วจับคู่กะวันหยุด
- ไม่ค้นหาก่อนช่วงที่พนักงานมีสิทธิ์ใน Schedule / ก่อนวันเริ่มงานตาม Access Engine

หน้าที่ใช้กฎเดียวกัน
- Popup กำหนดกะจากปฏิทินหลัก
- ตารางกะรายบุคคลเต็มเดือน
- Monthly Personal Overview
- รายทีม / Bulk
- Fill Down / Fill Right
- Copy / Paste
- คัดลอกสัปดาห์ก่อน
- รูปแบบกะ 7 วัน
- Undo / Redo

UX เพิ่มเติม
- ถ้าใช้กะย้อนหลัง แสดงวันที่และรหัสกะที่ใช้เป็นฐาน
- ถ้าไม่มีประวัติ แสดงว่าใช้ “กะตั้งต้น” แทน ไม่แจ้งผิดว่าไม่พบกะก่อนหน้า
- Copy/Paste/Fill กะวันหยุดข้ามพนักงาน จะ Normalize เป็นกะวันหยุดคู่ของพนักงานปลายทาง

3. รัน SQL_สำหรับตรวจสอบ_V6.13.5_CROSS_MONTH_DAYOFF_RESOLVER.sql
4. Deploy Web V6.13.5
