TimeClock Enterprise V6.15.08
Employee Portal — Leave Request Policy

Important
- Employee Portal leave request is for schedule adjustment ONLY.
- Employee must still enter leave in HR Connect.
- Official leave approval remains by Division-level supervisor.

Employee Portal rules
- Past-date leave requests are blocked. Today and future dates are allowed.
- Weekly day-off and public holiday cannot be requested as leave.
- Leave types:
  PERSONAL = ลากิจ
  VACATION = ลาพักร้อน
  ORDINATION = ลาอุปสมบท
  NEWBORN_CARE = ลาดูแลบุตรที่คลอดใหม่

Partial leave
- PERSONAL minimum 60 minutes.
- VACATION minimum 180 minutes.
- ORDINATION full day only and employee service >= 1 year.
- NEWBORN_CARE full day only.

UI
- Important HR Connect note added to Leave modal.
- Leave type is a controlled select list.
- Partial option is disabled automatically for full-day-only leave types.
- Date/time validation is shown before submit.
- Footer added: Design by ฝ่ายบริหารระบบข้อมูลบุคคล.

Manager
- Leave type labels are rendered in Thai.
- Request context explicitly reminds Manager that Portal request only changes
  schedule and HR Connect remains the official leave workflow.
