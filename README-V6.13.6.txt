Time-Clock Enterprise V6.13.6 — Person Full-Month Icon-only Labels

ฐาน: V6.13.5 Cross-Month Day-off Resolver

ปรับเฉพาะ UI ตารางกะรายบุคคล • เต็มเดือน
- Label ในช่องรายวันแสดง Icon อย่างเดียว
- กะเช้า = Sun
- กะดึก = Moon
- วันหยุด = Rest/Bed
- ลา = Document
- นักขัตฤกษ์ = Sparkles
- กะนับชั่วโมง = Clock
- เช้า+ดึก / Split = Two-way arrows
- รายละเอียดรหัสกะ เวลา รูปแบบ และสถานะอยู่ใน Tooltip
- เพิ่ม Legend icon ด้านบนตาราง
- Backend / SQL / Shift Code / Scheduling Rules / Quota / Calculation ไม่เปลี่ยน

ติดตั้ง
1. ไม่ต้องรัน SQL เพิ่ม หาก V6.13.5 ติดตั้งครบแล้ว
2. Deploy ไฟล์ V6.13.6
3. Ctrl + F5
4. เปิด ปฏิทินจัดกะ > มุมมองรายบุคคล
