Time-Clock Enterprise V6.11.52
Shift-2 Label + Compact Period Controls

1. ปฏิทินจัดกะ > มุมมองรายบุคคล
- แก้กะที่ 2 ไม่แสดงใน Label
- Work Plan metadata โหลดแบบ Batch 20 คน เพื่อไม่ชน 1,000-row limit
- วัน SPLIT_FLEX จะแสดงรหัสกะ 2 บรรทัดในช่องเดียวกัน
  บน = กะที่ 1
  ล่าง = กะที่ 2
- ถ้า Backend ไม่มีรหัสกะที่ 2 ระบบ Match Shift Master ก่อน
- ถ้าเป็น D5/D6 จะ fallback เป็น N5/N6
- Tooltip ยังคงแสดงรายละเอียดทั้ง 2 กะ

2. เดือนที่แสดง
- ตัด Banner เดือนขนาดใหญ่ที่แยกอยู่เหนือคำสั่งจัดกะ
- ย้ายชื่อเดือน/ปี เช่น "กรกฎาคม 2569"
  มาไว้ต่อจากคำว่า "เดือนที่แสดง" ใน Control ด้านบน
- ช่วงวันที่ / จำนวนวันยังแสดงด้านล่าง

3. มุมมองรายทีม
- ตัดส่วน Label ใหญ่ "สัปดาห์ที่แสดง"
- เหลือเฉพาะตัวเลือก "เลือกสัปดาห์"
- เดือนของรายการสัปดาห์อ้างอิงเดือนที่เลือกจากมุมมองรายบุคคล
- สลับจากรายบุคคลไปทีมแล้วไม่ย้อนกลับไปเดือนเก่าของทีม
