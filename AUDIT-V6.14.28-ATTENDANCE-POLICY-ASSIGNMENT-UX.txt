B. Canonical Attendance Policy V6.14.28
1. Workday + complete punch + late 1–29 นาที       => LATE / “มาสาย”
2. Workday + complete punch + late >=30 นาที       => ABSENT / UI “ขาดงาน”
3. Workday + missing IN / OUT / both                => UI “ขาดงาน”
   - เก็บ MISSING_IN / MISSING_OUT / MISSING_BOTH เป็น technical reason
   - absence_minutes ยังคง full-shift ตาม V6.6.4
4. Complete punch + OUT ก่อน shift end               => EARLY_LEAVE / “กลับก่อน”
5. >=30 นาที + กลับก่อน                              => Primary “ขาดงาน” และยังนับ “กลับก่อน” แยก
6. Leave / natural day-off / future planned day      => ไม่ถูกจัดเป็นขาดงานจากกฎนี้
7. Explicit working shift on natural OFF/HOL          => ถือเป็น expected workday
