ปรับเฉพาะ UX/UI ของ ตารางกะรายบุคคล • เต็มเดือน
- Hover Label: ลดการ scale และใช้กรอบ soft ring ที่สมบูรณ์
- Click/Selected: ใช้กรอบเดียวรอบ Icon tile ไม่ซ้อนกรอบ TD
- Row Hover: ชี้แถวพนักงานแล้ว highlight ทั้งแถวแบบอ่อน
- Sticky employee columns highlight ไปพร้อมกับแถว
- รองรับ Light/Dark Mode
- Tooltip / Icon-only / Full-month fit คงเดิม
- Business Logic / Backend / Shift Rules คงเดิมทั้งหมด
