Expected business examples
1) TECH_6D DAY S043, normal Sunday => OS043
2) TECH_6D DAY but latest work shift Saturday manually S135 => Sunday OS135
3) TECH_5D NIGHT S134, no prior work shift in 60 days => OS134 fallback
4) Public holiday with no explicit shift => HOL
5) Public holiday overridden by explicit working shift => employee works; day-off quota not consumed for that date
6) LV/LEAVE => day-off quota not consumed
7) Manager position configured TECH_6D => follows TECH_6D weekly_off_dows, not manager position rule
8) Work Pattern changes next month => quota and Schedule use the new month's weekly_off_dows
