Time-Clock Enterprise V6.12.0 — Scheduling Rules
=================================================
Base version: V6.11.57 Shift Code Migration

สิ่งที่เพิ่มในเวอร์ชันนี้
--------------------------
1. หน้า Work Pattern เพิ่ม Scheduling Rules สำหรับ HR Admin
   - เปิด/ปิดรูปแบบการทำงาน
   - กำหนดใช้ทุกหน่วยงาน หรือเฉพาะหน่วยงานที่เลือก
   - กะปกติ
   - กะปกติ + งานลูกค้าช่วงดึก (คงของเดิม)
   - กะเช้า + รอเข้ากะดึก
   - กะนับชั่วโมง
   - Smart OFF / วันหยุดตามกะล่าสุด

2. กะเช้า + รอเข้ากะดึก
   - เลือกกะช่วงแรกจาก Shift Master
   - ระบุเวลาออกช่วงแรก / กลับเข้าทำงาน / เวลาคาดว่างานเสร็จ
   - ชั่วโมงตามแผนไม่นับช่วง Waiting Gap
   - ระบบสร้าง Shift Code ภายในสำหรับช่วงแรกอัตโนมัติและซ่อนจาก User

3. กะนับชั่วโมง
   - User ระบุเฉพาะเวลาเริ่ม
   - เวลาสิ้นสุดคำนวณจาก scheduled_minutes_including_break ของ Work Pattern
   - Shift Code ภายในถูกสร้างอัตโนมัติและซ่อนจาก Shift Master ปกติ

4. กฎพักขั้นต่ำ 6 ชั่วโมง
   - เป็น Hard Block
   - ตรวจทั้ง Popup รายบุคคล และการจัดกะหลายช่อง/Fill/Pattern/Paste

5. ชั่วโมงทำงานต่อเนื่อง 48 ชั่วโมง
   - เป็น Warning ไม่ Block
   - User สามารถยืนยันเพื่อจัดกะต่อได้
   - Split Wait ไม่นับช่วงรอเป็นชั่วโมงทำงาน

6. Smart OFF
   - Shift Code หลักยังใช้ OFF เดิม
   - ระบบเก็บ off_window_start / off_window_end แยกตามพนักงานและวันที่
   - อ้างอิงกะทำงานล่าสุดอัตโนมัติ แม้มี OFF ต่อเนื่องหลายวัน
   - รองรับ Bulk / รูปแบบกะ 7 วัน

7. โควต้าวันหยุด
   - ผู้จัดการแผนก: เสาร์ + อาทิตย์ + วันหยุดนักขัตฤกษ์
   - ตำแหน่งอื่น: อาทิตย์ + วันหยุดนักขัตฤกษ์
   - วันเดียวกันที่เป็นทั้งวันหยุดประจำสัปดาห์และนักขัตฤกษ์นับเพียง 1 วัน
   - OFF/HOL ที่กำหนดจริงถือเป็นวันหยุดที่ใช้ไป
   - ยอดคงเหลือยกไปเดือนถัดไป
   - HR Admin กำหนดเดือนเริ่มนับได้จากหน้า Work Pattern

ลำดับการติดตั้ง
----------------
ระบบนี้สมมติว่า V6.11.57 ถูกติดตั้งและใช้งานอยู่แล้ว

   SQL_ที่ต้องรัน_V6.12.0_SCHEDULING_RULES.sql
3. จากนั้นรัน
   SQL_สำหรับตรวจสอบ_V6.12.0_SCHEDULING_RULES.sql
4. Hard Refresh หน้าเว็บ 1 ครั้ง

หมายเหตุสำคัญ
-------------
- ไม่ต้องสร้าง OFF-0830 / OFF-1930 แยกใน Shift Master
- Shift Code ที่มี note [SYSTEM_GENERATED_V6120] เป็นรหัสระบบ ห้ามแก้ไขด้วยมือ
- User จะเห็นชื่อกะและช่วงเวลาเป็นหลัก ส่วนรหัสกะจริงยังถูกเก็บในระบบเหมือนเดิม
- การ Copy/Fill ของกะพิเศษที่ระบบสร้าง (Hour Based / Split Wait) ถูก Block ไว้ เพื่อป้องกันการคัดลอกเฉพาะรหัสโดยไม่คัดลอกข้อมูลช่วงเวลา ให้เปิด Popup แล้วเลือกรูปแบบกะพิเศษแทน
- SQL ชุดนี้เพิ่มตารางและ RPC ใหม่ ไม่ลบข้อมูลตารางกะเดิม

กรณีทดสอบที่แนะนำ
------------------
A. 19:30-04:30 -> วันถัดไป 08:30-17:30 ต้อง Block เพราะพัก 4 ชั่วโมง
B. จัดกะต่อเนื่องจนเกิน 48 ชั่วโมง ต้อง Warning และยังเลือกจัดต่อได้
C. Split Wait 08:30-15:00 + 21:00-01:00 ต้องไม่นับ 15:00-21:00
D. Hour Based เริ่ม 04:00 ต้องคำนวณ End ตาม Work Pattern จริง
E. หลัง 19:30-04:30 กด OFF ต้องแสดง OFF 19:30-04:30
F. OFF ต่อเนื่อง 2 วัน ต้องยังอ้างอิงกะทำงานล่าสุด ไม่เปลี่ยนช่วงเวลา
G. ตรวจยอดโควต้า/ใช้ไป/ยกยอดเดือนถัดไป
