Time-Clock Enterprise V6.14.31
Night → Morning Minimum Rest UX + Quick Shift Consistency

เป้าหมาย
1. Popup กำหนดกะทำงาน: ถ้าวันก่อนหน้าเป็นกะดึกและกะเช้าวันถัดไปทำให้พัก < 6 ชม. ให้ Block พร้อมคำแนะนำที่ชัดเจน
2. ยังอนุญาตให้เลือกกะกลางคืน ถ้าระยะพักจริง >= 6 ชม.
3. แนะนำ "วันหยุดตามกะล่าสุด" เป็นทางเลือกหลัก และมีปุ่มเลือกกะกลางคืนแทนใน Popup
4. ปุ่มลัดเหนือตาราง รายบุคคล 15 วัน / เต็มเดือน ใช้ Precheck พักขั้นต่ำชุดเดียวกัน
5. ถ้าเลือกหลายช่องและบางช่องเป็น Night→Morning conflict ระบบข้ามเฉพาะช่องที่ Block และบันทึกช่องที่ผ่านได้
6. โหลดข้อมูลวันก่อนหน้าของช่วงที่แสดงแบบซ่อน เพื่อให้วันแรกของ 15 วัน/เต็มเดือนตรวจพักจากวันก่อนหน้าได้ถูกต้อง

ตัวอย่าง
- S134 19:30-05:00 -> STD 08:30 = พัก 3.5 ชม. => BLOCK
- S135 19:30-04:30 -> S043 08:30 = พัก 4 ชม. => BLOCK
- S134 19:30-05:00 -> S134 19:30 = พัก 14.5 ชม. => ALLOW
- S135 19:30-04:30 -> S135 19:30 = พัก 15 ชม. => ALLOW

Backend
- ใช้กฎ Minimum Rest 6 ชั่วโมงเดิมจาก V6.14.1 ต่อเนื่อง
- V6.14.31 เป็น Frontend-only ไม่ต้องรัน SQL ใหม่

Deploy
1. Deploy ZIP V6.14.31
2. Ctrl + F5
3. ทดสอบ Popup และปุ่มลัดทั้ง 15 วัน / เต็มเดือน
