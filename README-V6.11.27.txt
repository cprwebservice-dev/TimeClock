Time-Clock Enterprise V6.11.27
MONTHLY PERSONAL OVERVIEW UX + ST6 / ST5

ฐาน: V6.11.26

สิ่งที่ปรับ
1) MONTHLY PERSONAL OVERVIEW
- ปรับ Header ให้เห็นพนักงาน, รูปแบบ 5D/6D, กะมาตรฐาน และสถานะแก้ไขได้/ดูอย่างเดียวชัดขึ้น
- เพิ่ม KPI วันทำงาน / ขาดงาน / สาย / กลับก่อน / งานลูกค้าช่วงดึก
- เพิ่ม Insight จำนวนวันที่มีเวลาผิดปกติ
- ปรับปฏิทินรายวันให้เห็น Status, รหัสกะ, รหัสรูปแบบกะมาตรฐาน, เวลาเข้า/ออก และกะที่ 2 อ่านง่ายขึ้น
- ปุ่มจัดกะในแต่ละวันเด่นขึ้น และยังสัมพันธ์กับ System Period / รอบปิด ตาม V6.11.26
- ปรับ Responsive และ Dark Mode

2) รหัสรูปแบบกะมาตรฐาน
- SINGLE_0830_1730 -> ST6  (TECH_6D / 08:30-17:30)
- SINGLE_0830_1800 -> ST5  (TECH_5D / 08:30-18:00)
- SINGLE_0830 เดิม -> ST6
- SPLIT_FLEX ยังคงเดิมสำหรับ "กะปกติ + งานลูกค้าช่วงดึก"
- SQL จะสร้าง Master ใหม่, ย้าย Reference ที่ใช้งาน, ปรับ Runtime Functions และปิด Master Code เดิมเป็น Legacy
- Frontend รองรับ Legacy Code เพื่อให้ข้อมูลเดิมยังแสดงเป็น ST6/ST5 ได้ในช่วงเปลี่ยนผ่าน

ลำดับติดตั้ง
1. รัน SQL_ที่ต้องรัน_V6.11.27_ST5_ST6_TEMPLATE_CODES.sql
2. รัน SQL_สำหรับตรวจสอบ_V6.11.27_ST5_ST6_TEMPLATE_CODES.sql
3. ผลตรวจควร PASS ทุกข้อ
4. Deploy ไฟล์เว็บใน ZIP นี้
5. Ctrl + Shift + R
6. ตรวจ Build = V6.11.27
