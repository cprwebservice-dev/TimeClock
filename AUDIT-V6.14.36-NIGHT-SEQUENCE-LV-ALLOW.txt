AUDIT — TimeAttendance V6.14.36
Night Sequence Guard — Allow NIGHT -> LV

Business rule corrected from V6.14.35
1) A Night shift still cannot have morning/day work on the previous calendar day.
2) The next calendar day after a Night may be:
   - another Night shift
   - a true Day-off / HOL
   - Leave (LV)
3) LV remains Leave. It is NOT converted to Day-off and does not consume Day-off quota.
4) Minimum rest 6h and >48h warning remain unchanged.

Expected matrix
- DAY -> NIGHT = BLOCK
- NIGHT -> NIGHT = ALLOW subject to minimum rest >= 6h
- OFF/HOL/LV -> NIGHT = ALLOW subject to minimum rest where applicable
- NIGHT -> DAY = BLOCK
- NIGHT -> OFF/HOL = ALLOW
- NIGHT -> LV = ALLOW
- NIGHT -> LV -> DAY = ALLOW (the immediate successor of Night is LV)
- NIGHT -> LV -> NIGHT = ALLOW subject to the Night's previous-day rule (LV is not day-work)
