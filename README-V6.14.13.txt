Time-Clock Enterprise V6.14.13 — Person Month Copy Workflow

ปรับ UX มุมมองรายบุคคลสำหรับคัดลอกกะทั้งเดือนแบบเลือกจากตารางโดยตรง

Workflow
1) ติ๊ก Checkbox พนักงานต้นทาง 1 คน
2) แถวต้นทาง Highlight สีน้ำเงิน
3) กด “คัดลอกทั้งเดือน”
4) ติ๊ก Checkbox พนักงานปลายทางได้หลายคน
5) แถวปลายทาง Highlight สีเขียวอมฟ้า
6) กด “วางกะทั้งเดือน”
7) ตรวจ Preview / วิธีวาง / รายการที่จะข้าม
8) ยืนยันใน Popup ก่อนบันทึกจริง

กติกา
- LV และ HOL ไม่คัดลอก
- กะพิเศษที่ต้องเก็บช่วงเวลารายบุคคลจะข้าม
- วันหยุดคู่กันจะ Normalize ตาม Work Pattern ของปลายทาง
- ยังตรวจ Scope, Start Date, Minimum Rest 6 ชม., 48 ชม. และ Day-off Quota ก่อน Save
- Copy/Paste รายช่องเดิมยังทำงานแยกกัน

SQL
- ไม่ต้องรัน SQL เพิ่มจาก V6.14.12
