กฎกลาง V6.14.35
1) ถ้าวัน D เป็นกะดึก: D-1 ต้องไม่ใช่กะเช้า/กลางวัน
2) ถ้าวัน D เป็นกะดึก: D+1 ต้องเป็นกะดึก หรือ “วันหยุดจริง” เท่านั้น
3) LV = ลา ไม่ถือเป็นวันหยุดสำหรับข้อ 2
4) กะเช้า + งานลูกค้าช่วงดึก / กะเช้า + รอเข้ากะดึก ยังถือเป็น Day-starting workday
5) กะนับชั่วโมงที่เริ่ม >= 18:00 ถือเป็น Night
6) Minimum Rest < 6 ชั่วโมงยัง BLOCK เหมือนเดิม
7) >48 ชั่วโมงยัง Warning เหมือนเดิม
8) Day-off quota / Work Pattern / Scope / Start Date / System Period คงเดิม

Expected Matrix
- OFF/HOL -> NIGHT -> NIGHT -> OFF/HOL = ALLOW (ถ้าพักขั้นต่ำผ่าน)
- LV -> NIGHT -> NIGHT -> OFF/HOL = ALLOW (LV ก่อน Night ไม่ใช่กะเช้า)
- MORNING -> NIGHT = BLOCK
- NIGHT -> MORNING = BLOCK
- NIGHT -> LV = BLOCK
- NIGHT -> NIGHT = ALLOW ถ้าพัก >= 6 ชม.
- MORNING -> NIGHT -> MORNING = BLOCK
- เปลี่ยนวันนี้เป็น MORNING ขณะที่พรุ่งนี้เป็น NIGHT = BLOCK
